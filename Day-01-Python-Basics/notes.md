- Algorithms

- Arithmetic Operators

## 🧠 Key Concepts

### 1. Algorithms

An **algorithm** is a step-by-step procedure used to solve a problem.

Example: Algorithm to add two numbers:

1. Start
2. Take two numbers
3. Add the numbers
4. Display the result
5. Stop

Algorithms help us plan the solution before writing code.

### 2. Compiler and Interpreter

A **compiler** translates source code into a form that can be executed by a computer.

Python is generally executed using the **Python interpreter**. Python source code is compiled into bytecode and then executed by the Python virtual machine.

### 3. Variables

A **variable** is a name used to store a value.

```python
name = "Yashwith"
age = 20
marks = 85.5
```

Here:
- `name` stores a string.
- `age` stores an integer.
- `marks` stores a floating-point number.

### 4. Data Types

A data type describes the kind of value stored in a variable.

| Data Type | Example | Description |
|---|---|---|
| `int` | `20` | Whole number |
| `float` | `85.5` | Decimal number |
| `str` | `"Hello"` | Text |
| `bool` | `True` | True or False |

Example:

```python
name = "Yashwith"
age = 20
marks = 85.5
is_student = True
```

### 5. Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

| Operator | Operation | Example |
|---|---|---|
| `+` | Addition | `10 + 3` |
| `-` | Subtraction | `10 - 3` |
| `*` | Multiplication | `10 * 3` |
| `/` | Division | `10 / 3` |
| `//` | Floor division | `10 // 3` |
| `%` | Remainder | `10 % 3` |
| `**` | Power | `10 ** 3` |

Example:

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```
